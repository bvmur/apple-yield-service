# Урожайность сада яблонь — API

Все методы начинаются с `/api`, ответы в JSON. При ошибке в теле приходит пояснение: `{"detail": "Месяц не найден"}`.

## Методы: месяцы

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/api/months?temp_from=10` | список опубликованных месяцев, фильтр по температуре |
| GET | `/api/months/feed`, `/api/months/feed/{id}?next=true` | лента: один месяц; без id — первый, с `next=true` — следующий по кругу |
| GET | `/api/months/draft` | черновик текущего пользователя |
| POST | `/api/months` | создать черновик: название, фото и видео |
| PUT | `/api/months/draft/publish` | опубликовать черновик |
| DELETE | `/api/months/{id}` | удалить свой месяц |
| POST | `/api/months/{id}/like` | поставить или снять лайк |

**Список** — `GET /api/months`. Параметр `temp_from` необязательный: без него приходят все
опубликованные месяцы. Признак `is_mine` — 1, если месяц создал текущий пользователь, иначе 0.

```json
[
  {"id": 1, "title": "Апрель", "norm_temp": 6, "norm_precip": 40,
   "image_url": "http://localhost:9000/media/april.jpg", "likes_count": 4, "is_mine": 1}
]
```

**Лента** — `GET /api/months/feed`. Без id лента начинается с первого опубликованного месяца.
Чтобы перейти дальше, клиент передаёт id текущего месяца и `next=true`; после последнего
снова идёт первый. С id без `next` возвращается этот месяц. Признак `is_liked` — 1,
если текущий пользователь лайкнул месяц.

```json
{"id": 1, "title": "Апрель", "norm_temp": 6, "norm_precip": 40,
 "description": "Почки набухают и раскрываются...",
 "image_url": "http://localhost:9000/media/april.jpg",
 "video_url": "http://localhost:9000/media/april.mp4",
 "likes_count": 4, "is_liked": 1}
```

**Черновик** — `GET /api/months/draft`. Id не указывается: у пользователя может быть только
один черновик. Если черновика нет — 404.

**Создание** — `POST /api/months`, тело `multipart/form-data`:

| Поле | Тип |
|---|---|
| `title` | текст, 1–30 символов |
| `photo` | файл-изображение |
| `video` | файл-видео |

Файлы сохраняются в MinIO под новыми латинскими именами (`3f9a1c…e2.jpg`), в БД пишутся только
имена. Полные ссылки собираются при выдаче ответа. Ответ — 201 и созданный черновик.

**Публикация** — `PUT /api/months/draft/publish`, тело JSON:

```json
{"description": "Листопад, подготовка сада к зиме", "norm_temp": 2, "norm_precip": 50}
```

Температура от −50 до 50, осадки от 0 до 1000. Черновик получает статус `published`
и дату публикации.

**Удаление** — `DELETE /api/months/{id}`. Мягкое: строка остаётся в БД со статусом `deleted`.
Удалить можно только свой месяц. Ответ — 204 без тела.

**Лайк** — `POST /api/months/{id}/like`, тело `{"value": 1}` ставит лайк, `{"value": 0}` снимает.
Повторный запрос ничего не ломает.

```json
{"month_id": 2, "likes_count": 2, "is_liked": 1}
```

## Методы: пользователи

| Метод | Адрес | Что делает |
|---|---|---|
| POST | `/api/users/register` | регистрация |
| POST | `/api/users/login` | вход — заглушка до ЛР4 |
| POST | `/api/users/logout` | выход — заглушка до ЛР4 |

**Регистрация** — тело `{"username": "nikita_sad", "password": "secret123"}`. Логин 3–30 символов,
пароль от 6 символов. Пароль хранится только в виде хеша Argon2 и в ответах не возвращается.

```json
{"id": 8, "username": "nikita_sad"}
```

**Вход** возвращает текущего пользователя из `get_current_user()`, **выход** отвечает 204.

## Коды ответов

| Код | Когда |
|---|---|
| 200 | данные получены или изменены |
| 201 | месяц или пользователь создан |
| 204 | удалено, выход — тела нет |
| 400 | неверные данные: пустое название, не тот тип файла |
| 403 | попытка удалить чужой месяц |
| 404 | месяца или черновика нет (удалённые тоже считаются несуществующими) |
| 409 | черновик уже есть, логин уже занят |
| 422 | тело не прошло проверку схемы: не хватает поля, лишнее поле, число вне диапазона |

Системные поля (`id`, `status`, `creator_id`, даты) с клиента не принимаются: в JSON-схемах
лишние поля запрещены, и такой запрос получит 422.

## Таблицы БД

### users — пользователи

| Поле | Тип | |
|---|---|---|
| `id` | integer | первичный ключ |
| `username` | varchar(30) | уникальный логин |
| `password` | varchar(128) | хеш пароля |

### months — месяцы (услуги)

| Поле | Тип | |
|---|---|---|
| `id` | integer | первичный ключ |
| `title` | varchar(30) | название |
| `image_url` | varchar(200) | имя файла фото в MinIO |
| `video_url` | varchar(200) | имя файла видео в MinIO |
| `description` | varchar(1000) | описание, может быть пустым |
| `norm_temp` | smallint | норма температуры, °C, может быть пустой |
| `norm_precip` | smallint | норма осадков, мм, может быть пустой |
| `status` | varchar(20) | `draft`, `published` или `deleted` |
| `created_at` | timestamp | дата создания |
| `formed_at` | timestamp | дата публикации, может быть пустой |
| `creator_id` | integer | автор → `users.id` |

Четыре поля могут быть пустыми: их заполняют не при создании, а при публикации.
У одного пользователя может быть только один черновик — это проверяет частичный уникальный
индекс по `creator_id` для строк со статусом `draft`.

### month_likes — лайки

| Поле | Тип | |
|---|---|---|
| `id` | integer | первичный ключ |
| `user_id` | integer | кто лайкнул → `users.id` |
| `month_id` | integer | что лайкнул → `months.id` |

Пара `user_id` + `month_id` уникальна: один пользователь ставит месяцу не больше одного лайка.
